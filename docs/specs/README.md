# Specs — 시스템·화면별 상세 스펙

1 시스템 = 1 파일. 시스템이 만드는 **화면(조작·레이아웃·연출)도 같은 파일에** 적는다.
구현 전에 스펙을 먼저 쓴다 (AGENTS.md CRITICAL 1). 새 스펙은 [_TEMPLATE.md](_TEMPLATE.md)를 복사해 작성한다.
화면 ID(S-xx)는 [PRD.md](../PRD.md)의 화면 목록과 같다.

> 이 폴더는 `execute.py`가 프롬프트에 자동 주입하지 **않는다** (전부 넣으면 프롬프트가 비대해진다). step 파일의 "읽어야 할 파일"에 필요한 스펙 경로를 반드시 명시하라.
