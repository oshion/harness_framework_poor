# Tech Debt Tracker

> 에이전트는 git log를 맥락으로 읽지 않는다. 알려진 부채는 반드시 여기에 남긴다 (`execute.py`가 매 step 프롬프트에 주입).
>
> - 발생 즉시 기록한다. 해결되면 "해결된 부채"로 옮기고 삭제하지 않는다.
> - 심각도: **높음** = 버그·보안·타입 안전성에 영향 / **중** = 규칙 임시 우회, 중복 / **낮음** = 동작 영향 없는 리팩터링
> - "높음"이 3개 이상이면 다음 마일스톤 시작 전에 해소한다.
