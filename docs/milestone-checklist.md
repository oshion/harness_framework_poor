# 마일스톤 완료 테스트 체크리스트

> 각 마일스톤이 끝나면 바로 이 체크리스트로 **사람이 직접** 테스트한다. 자동 테스트가 못 잡는 "실제로 쓸 만한가"를 확인하는 단계다.
> 개발 작업 목록은 [progress.md](progress.md).
> **모든 항목을 통과해야 다음 마일스톤을 시작한다.** 실패한 항목은 맨 아래 "결과 기록"에 적고, 고친 뒤 그 항목만 다시 확인한다.

## 테스트 환경

| 항목 | 내용 |
|---|---|
| 스테이징 | {예: 개인 서버 IP:포트}. 접속 주소·키·계정은 **저장소에 적지 않는다** |
| 접근 제한 | {예: 보안 그룹 IP 제한 또는 Basic 인증, `noindex`} |
| 브라우저·기기 | {예: Chrome, Edge, Firefox} |
| 화면 크기 | {예: 1920×1080, 1366×768} |

### 공통 (모든 마일스톤 끝에 확인)
- [ ] 로컬에서 `npm run check`, `npm run build`, `npm run test:e2e` 통과
- [ ] CI 통과
- [ ] 스테이징에 이 마일스톤 빌드가 올라가 있고, 접속하면 바로 뜬다
- [ ] 대상 화면 크기에서 화면이 잘리거나 겹치지 않는다
- [ ] 개발자 도구 Console에 에러가 없다
- [ ] progress.md 해당 항목이 모두 체크돼 있고, 새 기술 부채는 tech-debt-tracker.md에 있다

## M0. 기반

**화면**
- [ ] 스테이징 주소로 열면 빈 화면이 뜬다

**규칙이 자동으로 막히는지** (일부러 틀린 코드를 넣어 보고 되돌린다)
- [ ] 금지된 import·API를 쓰면 린트가 실패한다
- [ ] 잘못된 데이터 파일을 넣으면 로더가 에러를 낸다
- [ ] 테스트 없이 TDD 대상 파일을 만들려 하면 tdd-guard 훅이 막는다

**배포**
- [ ] 배포 순서가 문서에 있고, 그대로 따라 하면 다시 배포된다
- [ ] 이전 버전으로 되돌리는 방법이 있다
