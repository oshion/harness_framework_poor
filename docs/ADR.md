## 작성 규칙

- 새 결정은 맨 아래에 `ADR-NNN`으로 추가한다. 번호는 재사용하지 않는다.
- 결정을 뒤집을 때 기존 항목을 지우지 않는다. 상태를 `대체됨 (→ ADR-NNN)` 또는 `보류`로 바꾸고 새 항목을 추가한다.
- 형식: **상태 / 날짜 → 맥락 → 결정 → 트레이드오프**
